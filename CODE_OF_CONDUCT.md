# Code of Conduct

## Our Pledge

We aim to make this project useful for open science contributors with different
backgrounds and skill levels.

## Expected Behavior

- Be respectful and evidence-focused.
- Keep scientific claims conservative and reviewable.
- Credit data sources and contributors.
- Avoid harassment, insults, or personal attacks.

## Unacceptable Behavior

- Uploading or soliciting credentials.
- Presenting demo outputs as confirmed scientific discoveries.
- Publishing private data without permission.
- Harassment or abusive conduct.

Maintainers may remove content or block participation that violates these rules.
